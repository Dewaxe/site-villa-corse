# Site Villa Corse

Site vitrine français pour une villa à Cargèse (Corse-du-Sud), avec vue mer, galerie photographique immersive, présentation du logement, articles de recommandations, itinéraires animés, avis modérés et FAQ. Les réservations sont gérées exclusivement par **Amivac**. Projet d'apprentissage et d'ingénierie professionnelle mené par William Dempuré pour un proche.

**Statut au 05/11/2026 : cadrage fonctionnel terminé, étude de faisabilité technique à lancer.** Ce dossier est un *kit de démarrage documentaire*, **pas** une application développée ou une architecture déjà validée.

## Contraintes principales

- 0 € de dépense **et de risque de facturation automatique** (hors nom de domaine déjà possédé).
- Site public en français ; excellente ergonomie à la fois sur mobile et sur desktop.
- Dépôt GitHub public ; deux administrateurs distincts avec les mêmes droits.
- Nom commercial, sous-domaine exact et adresse du logement encore à communiquer.
- Contenus et médias sous contrôle du propriétaire ; sauvegarde et restauration prévues.
- Développement incrémental, CI, tests, validation humaine, journal d'apprentissage et suivi Notion.
