# État du projet

**10/11/2026 — M0, prototype local en cours.**

- **Prochaine tâche** — Confirmer Workers Free sur le compte Cloudflare, puis préparer une preview Pages isolée en lecture seule. Voir le [plan M0](M0.md#vérifications-avant-et-pendant-la-preview).
- **Décisions** — [ADR-001](DECISIONS.md#adr-001--hébergement-et-stack-full-stack) propose Pages + Functions + D1 + KV. IONOS reste le DNS autoritatif. La stack et le routage de production attendent les preuves du prototype.
- **Vérifié** — Le cadrage est publié sur [GitHub](https://github.com/Dewaxe/site-villa-corse/tree/main). Sur `m0/routage-pages`, trois tests HTTP/artefact réussissent avec Wrangler local. Le témoin dynamique est marqué, l’accueil et le CSS sont servis sans marqueur, et les routes admin testées renvoient 403. Le banc KDF local mesure des médianes HTTP de 345,2 ms (PBKDF2) et 189,7 ms (scrypt), pour 4,4 ms au témoin. Le banc WebAuthn synthétique accepte deux identités, refuse le rejeu local et mesure 5,6 ms de latence HTTP médiane. Dans Edge avec authentificateurs virtuels, deux comptes passent le parcours WebAuthn/D1, y compris le refus du rejeu, la rotation et la révocation. La clé de secours, la révocation de la clé perdue et la protection de la dernière clé sont vérifiées dans Edge. Le cycle WebP/article passe dans Edge et D1/KV locaux. La restauration et un export/import D1/KV dans un état neuf restituent le même HTML et les mêmes images. L’orthophoto IGN est vérifiée dans Edge aux zooms 15 et 17, avec repli testé sur deux tailles de fenêtre. La suite complète passe en local et sur le [premier runner GitHub Actions](https://github.com/Dewaxe/site-villa-corse/actions/runs/42874703665). L’artefact Pages en lecture seule est ajouté à la suite et testé avec les données D1/KV restaurées.
- **À valider** — Réenrôlement après perte des deux clés, appareils physiques, CPU, validation complète du bitstream, sauvegarde hébergée et retour de déploiement, carte sur appareils physiques, compte Free et réglage Fail closed en preview. Le sous-domaine reste à choisir.
- **Prévisualisation** — Conditions publiques Free vérifiées. Wrangler n’est pas connecté à Cloudflare dans cet environnement. Le plan du compte, les bindings distants, les métriques et Fail closed restent à vérifier.
- **Suivi** — Le [prototype M0](https://github.com/Dewaxe/site-villa-corse/tree/m0/routage-pages) est sur une branche dédiée. La décision de faisabilité est suivie dans « Site Villa Corse — Pilotage ». Les liens Notion privés restent hors dépôt public.
